## K. Next Engineering Recommendation

**العنوان:** Harden StableAnswerResultSet storage permissions in deploy/runtime bootstrap  

**الغرض:** ضمان أن مسار PHP-FPM يستطيع دائماً إنشاء/كتابة `storage/app/scientific_stable_results` دون فشل صامت `result_set_failure` بعد إعادة إنشاء المجلدات كـ root.  

**النطاق:** سكربت تهيئة نشر أو خطوة Docker entrypoint ضيقة فقط — دون إعادة تصميم التخزين أو تغيير عقد الترقيم.  

**معايير القبول:** بعد نشر نظيف، بحث علمي حي عبر الواجهة يُنشئ `stable_result_set.created=true` مع `result_set_id` صالح دون تدخل يدوي لـ `chown`.  

**لا تُنفَّذ هذه التوصية ضمن 6.5 — تتطلب موافقة مستقلة.**
