# 10 — Remaining Limitations

1. Synthesis remains partially extractive for main answer body (findings still evidence-bound excerpts); integrator adds structured notes, not full multi-condition scientific reasoning.
2. Conflict polarity lexicon is English-keyword based (pre-existing); Arabic polarity strength still limited.
3. Condition inference from free text is conservative hints only (method/climate/design) — does not invent dosages/sample sizes.
4. Live retrieval / UI / Flutter verification NOT_RUN.
5. Deep claim decomposition for arbitrary multi-part natural language beyond requested-property splits remains limited to existing QuestionClaimExtractor.
6. No automatic resolution of genuine conflicts (by design).
