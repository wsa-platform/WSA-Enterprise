تأكد من أن:
1. Commit واحد جديد فقط أُنشئ بواسطة هذه المهمة.
2. عنوان Commit يطابق الرسالة المطلوبة.
3. الملف الوحيد ضمن Commit هو ADR-023.
4. لم تُضمّن تغييرات محلية أخرى.
5. لم يُنفّذ Push.
6. لم تُحذف أو تُستبدل أي تغييرات محلية أخرى.
7. بقيت جميع التغييرات غير المرتبطة محفوظة.
لا تدّعِ أن شجرة العمل نظيفة إذا بقيت فيها تغييرات سابقة.
إذا فشل التحقق بعد Commit، لا تحاول التراجع عنه أو إعادة كتابة التاريخ تلقائيًا. سجّل المشكلة وأوقف العمل.

# 13. التقرير النهائي المطلوب
قدّم تقريرًا واحدًا شاملًا باللغة العربية، ويحتوي على:
## A. الملخص التنفيذي
- هل نجحت المراجعة؟
- هل أُنشئ Commit؟
- ما القرار النهائي؟
## B. حالة Git قبل التنفيذ وبعده
- HEAD قبل وبعد.
- الفرع.
- حالة الفهرس.
- عدد الملفات المعدلة وغير المتعقبة.
- أي اختلافات عن خط الأساس.
## C. نتائج البوابات
جدول يحتوي على:
- اسم البوابة.
- الفحص المنفذ.
- الأدلة.
- النتيجة: PASS أو FAIL أو BLOCKED.
- تفسير النتيجة.
## D. خريطة الترقيم والإحالات
- الأقسام المنشورة.
- الأقسام المحلية.
- العناوين الفرعية.
- الإشارات التاريخية.
- أي إحالات متبقية أو ملاحظات.
## E. حفظ المحتوى
- نتائج المقارنة.
- نتائج اختبار العكس.
- أي قيود على إثبات الحفاظ على النص.
## F. `git diff --check`
- Exit code.
- حالة الملاحظات.
- هل هي قديمة أم جديدة أم غير محسومة؟
## G. نتيجة Commit
إذا نجحت جميع البوابات، سجّل:
- Commit hash.
- Commit subject.
- الملفات المضمنة.
- نتيجة التحقق بعد Commit.
- تأكيد صريح بأن Push لم يُنفّذ.
إذا توقفت العملية، سجّل:
- سبب التوقف.
- المشكلة والأدلة.
- الحل المقترح.
- تأكيد صريح بأنه لم يُنشأ Commit ولم يُنفّذ Push.
## H. القرار النهائي
اختر حالة واحدة فقط:
`COMMITTED_NO_PUSH`
تعني أن جميع البوابات اجتازت الفحوص، وأُنشئ Commit محلي لملف ADR-023 وحده، ولم يُنفّذ Push.
`BLOCKED`
تعني أن مشكلة أو غموضًا منع Commit، مع الحفاظ على العمل المحلي وعدم تنفيذ Push.
`COMMIT_CREATED_POSTCHECK_FAILED`
تعني أن Commit أُنشئ بعد اجتياز البوابات، لكن فشل فحص لاحق. في هذه الحالة لا تنفّذ أي تراجع أو إصلاح تلقائي؛ وثّق المشكلة فقط.

# 14. قاعدة القرار النهائية
الأولوية القصوى:
1. سلامة السجل المعماري.
2. الحفاظ على جميع التغييرات المحلية.
3. عدم إدخال ملفات أخرى إلى Commit.
4. صحة الترقيم والإحالات.
5. إثبات الحفاظ على المحتوى.
6. نجاح جميع البوابات قبل Commit.
7. عدم تنفيذ Push.
ابدأ بالفحص، ونفّذ المراجعة كاملة.
**إذا اجتازت جميع البوابات، أنشئ Commit محليًا لملف ADR-023 وحده، ثم تحقق من النتيجة. إذا ظهرت أي مشكلة أو بقي أي شرط جوهري غير محسوم، فتوقف دون Commit، واعرض المشكلة والحل المقترح. لا تنفّذ Push تحت أي ظرف.**
