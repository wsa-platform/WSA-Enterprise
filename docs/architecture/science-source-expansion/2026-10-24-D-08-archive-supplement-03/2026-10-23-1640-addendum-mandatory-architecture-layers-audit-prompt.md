### 3. تتبّع التكامل بين الطبقات
بعد فحص كل طبقة منفردة، ارسم مسار البيانات الفعلي من المصدر إلى النتيجة، مع التمييز بين المسارات التي ثبت وجودها والمسارات المفترضة.
افحص المسارات التالية:
1. **مصدر علمي ← سجل المصادر ← عقد القدرات ← تنفيذ البحث ← تطبيع النتائج ← حفظ المعرفة العلمية المؤهلة.**
2. **مهمة أو جلسة تنفيذ ← برومبت ← تقرير ← أدلة وملفات مرتبطة ← أرشيف المهمة.**
3. **قرار معماري ← تنفيذ برمجي ← اختبار ← تقرير نتيجة ← توثيق في السجل المعماري.**
4. **سجلات IC ← طبقة IC Persistence ← المستهلكون الفعليون لهذه السجلات.**
لكل مسار، وثّق نقطة الدخول، والمكونات الوسيطة، ومصدر الحقيقة، ومكان التخزين، ومعالجة الأخطاء، والاختبارات المتاحة.
