أنت تعمل كمهندس برمجيات أول، ومراجع معماري، وخبير Git، ومسؤول عن سلامة السجل المعماري في مشروع WSA-Enterprise.

# 3. المرحلة صفر — حماية الحالة الحالية
قبل أي تعديل:
1. تحقّق من المسار الفعلي للمستودع والفرع وHEAD.
2. افحص:
   - `git status --short`
   - `git status --branch --short`
   - `git rev-parse HEAD`
   - `git rev-parse origin/phase-18-m18-ai-marketing-communications` إن كانت قيمة المرجع المحلي متاحة.
   - `git diff --cached --stat`
   - `git diff --stat`
   - `git diff --check`
3. لا تنفّذ `git fetch` إلا إذا كان ضروريًا للتحقق من حالة المرجع المنشور، وكان ذلك آمنًا. لا تغيّر أي ملفات محلية أو فهرس Git أثناء الفحص.
4. افحص حالة أي Git operation جارية، مثل merge أو rebase أو cherry-pick، دون محاولة إنهائها.
5. تحقق من أن الملف المستهدف موجود، وسجّل حجمه وSHA-256 الحاليين.
6. افحص وجود ملفات أخرى معدّلة أو غير متعقبة. اعتبرها جميعًا مواد محلية محمية.
أنشئ سجلًا مؤقتًا للمقارنة خارج مسارات المشروع التي قد تتأثر، أو في مسار تقارير مخصص لا يتعارض مع الملفات الحالية. لا تستبدل ملفًا موجودًا ولا تحذف أي ملف.
إذا تغيّر HEAD عن القيمة المتوقعة، أو أصبح الفهرس غير فارغ، أو وُجدت عملية Git نشطة، أو اكتشفت تعديلًا جديدًا غير مفهوم، فتوقّف عن التعديل وقدم تقريرًا يشرح الحالة الجديدة.
لا تستخدم أوامر قد تستبدل العمل المحلي، ومنها:
`git reset --hard`, `git clean`, `git checkout --`, `git restore`, `git stash`, أو أي إجراء مماثل.

- حالة الفرع المحلي والمنشور.
- حالة الفهرس.
- عدد الملفات المعدلة وغير المتعقبة قبل التنفيذ وبعده.
- SHA-256 للملف المستهدف قبل التنفيذ وبعده.
## 3. خريطة الترقيم
جدول بالأعمدة:
- المصدر
- الرقم القديم
- العنوان
- الرقم الجديد
- سبب التغيير
- حالة الإحالات
- نتيجة التحقق
## 4. حفظ السجل
- عدد الأقسام المحفوظة.
- تأكيد الحفاظ على الأقسام المنشورة §8.27–§8.29.
- تأكيد حفظ القرارات والتقارير والـ Prompts والمراجع.
- قائمة بأي استثناء أو مادة لم يمكن التحقق منها.
لا تدّعِ التحقق الكامل إذا لم يتم فحص المحتوى فعليًا.
## 5. نتائج الاختبارات
لكل اختبار:
- الأمر المنفذ.
- النتيجة الفعلية.
- Exit code عند توفره.
- PASS أو FAIL أو BLOCKED.
- أي قيود على الثقة في النتيجة.
## 6. الملفات المتأثرة
- الملفات التي عدّلتها هذه المهمة.
- الملفات المحلية السابقة التي لم تلمسها.
- أي مراجع خارجية تحتاج إلى مهمة مستقلة.
## 7. حالة Git النهائية
اذكر صراحة:
- هل تغيّر HEAD؟
- هل أُنشئ Commit؟ يجب أن تكون الإجابة: لا.
- هل أُجري Push؟ يجب أن تكون الإجابة: لا.
- هل تغير أي ملف آخر بسبب هذه المهمة؟
- هل بقيت تغييرات محلية أخرى محفوظة؟
## 8. قرار الجاهزية
اختر حالة واحدة فقط:
- `READY_FOR_FINAL_REVIEW` — الترقيم والإح
