### 4. فحص Git المحلي والبعيد

افحص تاريخ Git المحلي أولًا، ثم استخدم فقط بيانات GitHub المتاحة مسبقًا أو أداة GitHub المصرح بها إذا كانت متاحة دون تعديل.

حدّد بدقة:

- هل commit المرجعي موجود في التاريخ المحلي؟
- هل توجد commits لاحقة مرتبطة بـ Capability Store Persistence أو IC Persistence أو ADR-023؟
- هل commit المرجعي مدمج في الفرع الحالي، أم منفصل، أم أن الأدلة غير كافية؟
- ما آخر commit يمكن إثباته للفرع المحلي؟
- ما آخر commit يمكن إثباته للفرع البعيد من البيانات المتاحة؟
