## D. Permission Security Assessment

### طبقات الأمن (منفصلتان)
- **Filesystem:** هوية العملية المحلية (www-data مقابل others).
- **Application:** Public Tenant يربط `organization_id`؛ `pageStableResultSet` يقرأ فقط تحت مجلد المنظمة.

### الجرد التشغيلي
| العملية | UID | الدور |
|---|---|---|
| php-fpm master | 0 | طبيعي لفصل الامتيازات — ليس ثغرة وحده |
| php-fpm pool www | 33 (`www-data`) | كاتب/قارئ التخزين |
| www-data groups | 33 فقط | لا مجموعات إضافية |
| nobody | 65534 | هوية محلية غير مخوّلة للتخزين |

### القرار النهائي للأوضاع
| الهدف | الوضع | المبرر |
|---|---|---|
| مجلدات النتيجة | `2770` (فعّال مع setgid على 9p بعد recreate) | owner/group فقط؛ يغلق traverse/read لـ others |
| ملفات JSON | `0660` | يغلق قراءة others التي ثبتت تحت `0664` |
| اختبار nobody | قبل التشديد: قراءة ممكنة؛ بعد التشديد: مرفوضة؛ الكتابة مرفوضة دائماً | C66-06 |
| www-data | قراءة/كتابة OK بعد التشديد | لا كسر لسلوك شرعي |

**التهديد:** حدود الحاوية + عدم وجود مستخدم تطبيقي غير `www-data` يحتاج الملفات. تشديد others دفاع متعمق مُبرَّر بالدليل وليس تشديداً رقمياً اعتباطياً.

### عزل المنظمة (تطبيقياً)
